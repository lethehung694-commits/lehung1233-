VẠCH ĐÍCH – Website bán đồ thể thao (PHP + MySQL, chạy trên XAMPP)

1. Giải nén thư mục "vachdich" vào C:\xampp\htdocs\
2. Bật Apache và MySQL trong XAMPP.
3. Mở http://localhost/vachdich/setup.php , nhập email + mật khẩu quản trị, bấm "Chạy cài đặt".
4. Xóa file setup.php.
5. Trang chủ: http://localhost/vachdich/   Quản trị: http://localhost/vachdich/admin/
6. Chép ảnh sản phẩm vào uploads/products/ (tên file theo cột image_url).

Cấu hình (tên shop, hotline, phí ship, ngưỡng miễn phí ship): đầu file config.php.
